# Lab Template

Template output:

```text
README.md
AGENTS.md
lab/
  intent/
  reality/
  delta/
  behavior/
  evidence/
docs/
  README.md
  project-structure.md
lab.yaml
```

Files under **`template/root/`** (`README.md`, `AGENTS.md`) merge into the **target root** on init. Root `docs/` is a **recommended companion** (mini-index + structure stub). These paths are copied for convenience and are **not** enforced by `validate`—you may delete or replace them.
