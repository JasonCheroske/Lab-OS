# LAB OS Manifesto

**Intent:** Capture the core principles that guide how the lab system is designed and operated.

**Related paths:** [README.md](README.md), [GOVERNANCE_MODEL.md](GOVERNANCE_MODEL.md), [MATURITY_MODEL.md](MATURITY_MODEL.md)

**Last reviewed:** 2026-03-26 - migrated into taxonomy structure and standardized metadata.

## Purpose

Provide a portable operating model for AI-native engineering laboratories.

## Principles

1. Freedom of implementation with consistency of outcomes.
2. Architecture intent is explicit and reviewable.
3. Protected changes require social sign-off.
4. Knowledge is cumulative and acyclic.
5. Stage progression requires evidence, not assumptions.
