# Agnostic rules

Rules placed here apply **regardless of which AI harness** you use. They are written as plain guidance any agent or human can follow without harness-specific config syntax.

When editing **Markdown** elsewhere in this repo: use **exactly one** YAML frontmatter block at the top (`created` / `updated`); do not stack a second `---` block before the title or body. Policy and tooling: [`docs/00-index/DOC_GOVERNANCE.md`](../../docs/00-index/DOC_GOVERNANCE.md) and [`scripts/add-md-frontmatter.mjs`](../../scripts/add-md-frontmatter.mjs).
